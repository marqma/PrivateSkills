# PrivateSkills

Private collection of custom Copilot skills and extensions.

## Layout

- `skills/` — user-level skills
- `extensions/` — user-level Copilot extensions

## Documentation

- `skills/README.md` — overview of all skills, including available commands, purpose, and example use cases

This repository is intended to be the canonical backup and synchronization target for these custom artifacts. Do not add credentials, tokens, private keys, or environment files.
